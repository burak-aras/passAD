🤖 Otomatik Şifre Sona Erme Kontrolü (Zamanlanmış Görev)

Açıklama: Sistem otomatik olarak (cron job veya Windows Task Scheduler ile) belirli aralıklarla çalışır ve şifresi yakında sona erecek kullanıcılara otomatik email gönderir. Admin müdahalesi gerekmez.
sequenceDiagram participant Scheduler as ⏰ Zamanlanmis Gorev participant Container as 🐳 Docker Container participant Job as 🤖 Expiry Job participant AD as 🏢 Active Directory participant Token as 🔑 Token Service participant Email as 📧 Email Service participant Users as 👥 Kullanicilar Note over Scheduler: Zamanlanmis gorev: Her Pazartesi 12:00 Scheduler->>Container: docker-compose run password-expiry-job Container->>Job: Container baslat Job->>AD: Tum kullanicilari sorgula (LDAP) AD-->>Job: Kullanici listesi + sifre sona erme tarihleri Note over Job: Filtreleme: 0-60 gun arasi loop Her kullanici icin alt Sifre yakinda sona erecek Job->>Token: Token olustur Token-->>Job: Token + Link Job->>Email: Uyari emaili hazirla Email->>Users: Email gonder end end Job-->>Container: Islem tamamlandi (log) Container-->>Scheduler: Container kapandi (exit 0) Note over Scheduler: Bir sonraki hafta tekrar calisacak
📋 Akış Detayları:

1. Zamanlanmış Tetikleme: Cron job veya Windows Task Scheduler her gün belirli saatte (örn: 08:00) job'ı otomatik başlatır
2. Kullanıcı Sorgulama: Active Directory'den tüm kullanıcılar ve şifre sona erme tarihleri sorgulanır (LDAP)
3. Filtreleme: Şifresi 0-60 gün içinde sona erecek kullanıcılar filtrelenir
4. Email Gönderimi: Her kullanıcı için benzersiz token oluşturulur ve şifre sıfırlama emaili gönderilir
5. Loglama: Tüm işlemler veritabanına kaydedilir
6. Tamamlanma: Container kapanır ve bir sonraki gün tekrar çalışmak üzere bekler
💡 Zamanlanmış Görev Kurulumu:

Linux/Unix (Cron):
0 8 * * * cd /path/to/app && docker-compose run --rm password-expiry-job

Windows (Task Scheduler):
Program: docker-compose
Arguments: run --rm password-expiry-job
Working Directory: C:\Users\User\Desktop\yedek\app
Schedule: Günlük, 08:00
